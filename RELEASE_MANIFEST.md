# VLMB Music Bot 4.0.0-rc2

Architecture & Reliability release candidate after Phase 1/2 foundation work.

## Included

- Callback namespace catalog + static callback audit.
- Explicit critical-flow state machine and regression tests.
- `application/`, `domain/`, `providers/`, and `storage/` boundaries.
- `SearchMusic` and `DownloadTrack` application use cases.
- Unified provider adapter contract, failover and circuit breaker.
- Bounded download queue with bounded retries, idempotent submission and graceful shutdown API.
- Provider health and P50/P95/P99 latency metrics.
- Safe structured event logging with credential redaction.
- SLO definitions, security controls and threat model.
- Release artifact integrity audit rejecting generated bytecode/cache directories.
- CI clean-checkout artifact gate.
- Deterministic queue/load smoke and rollback drill.

## Migration status

The 4.0 architecture remains an incremental boundary extraction. `music_bot_user_mixes.py` is still the compatibility bootstrap; legacy behavior is preserved until extracted flows are tested and verified.

## Release identity

- Version: `4.0.0-rc2`
- Source branch: `master`
- Source commit for the package: recorded at package build time.
- Python: 3.12 CI baseline.

## Production policy

This RC is not production-approved until CI, package validation and server-side smoke tests pass. Keep the pre-release backup until acceptance is complete.

## Security

No `.env`, tokens, production databases, logs, virtualenvs, or generated bytecode are included in the release archive.
